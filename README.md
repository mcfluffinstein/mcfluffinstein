# Hey, I'm Alex 👋

I work on GitHub's Enterprise Support team, where I resolve complex technical
escalations, contribute production code to the Rails monolith, and build
internal investigation tooling.

My work spans hosted and on-premises enterprise platforms, APIs, authentication,
integrations, infrastructure, and distributed systems. I am most interested in
the judgment-heavy problems: tracing failures across production systems,
evaluating security and rollout risks, separating evidence from assumptions,
and making complex findings useful to customers and engineers.
